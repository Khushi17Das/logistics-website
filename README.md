# 🚚 Logistics Website

A modern, responsive, and professional logistics company website built to showcase transportation, freight, and supply chain services. The website features a clean business-oriented design, intuitive navigation, and a fully responsive layout to provide an excellent user experience across desktop, tablet, and mobile devices.

## ✨ Features

- Modern and responsive UI
- Professional landing page
- Company information section
- Logistics and transportation services
- Contact section
- Smooth scrolling navigation
- Mobile-friendly design
- Optimized performance
- Clean and maintainable code structure

## 🛠️ Tech Stack

- HTML5
- CSS3
- JavaScript

## 🚀 Getting Started

### Clone the repository

```bash
git clone https://github.com/Khushi17Das/logistics-website.git
```

### Navigate to the project directory

```bash
cd logistics-website
```

### Run the project

Simply open the `index.html` file in your browser, or use a local development server such as Live Server in VS Code.
